1. ЧТО ЭТО ЗА ПРОДУКТ И КОМУ НУЖЕН
================================================================================

AutoPost Bot — это SaaS-сервис для блогеров и владельцев Telegram-каналов,
которые зарабатывают на партнёрских программах.

Проблема пользователя:
- Вручную искать товары со скидками, оформлять посты, ставить ERID-маркировку,
  следить за расписанием — долго и легко ошибиться.
- Рекламные кампании (CPC) требуют отдельных постов с правилами.

Решение:
- Пользователь подключает Telegram-канал и выбирает магазины.
- Бот сам подтягивает товары с партнёрскими ссылками и ERID.
- Бот публикует по расписанию: точное время на каждый магазин или интервал.
- Веб-панель показывает статистику (клики, лиды, деньги), управляет шаблонами,
  выплатами и чеками.
- Админка позволяет владельцу сервиса управлять пользователями и выплатами.

Модель монетизации сервиса:
- Пользователь получает комиссию с покупок (например 70%, настраивается).
- Сервис удерживает свою долю.
- Вывод денег — по заявкам, с обязательным чеком из "Мой Налог".

Статус: продукт рабочий, готовится к питчу технологического партнёрства Admitad.
Требование: всё должно быть идеально к моменту ответа Admitad.

2. РОЛИ ПОЛЬЗОВАТЕЛЕЙ
================================================================================

1) SaaS-пользователь (основной):
- Выбирает CPA-магазины.
- Настраивает интервал, дни недели, автоудаление, закрепление.
- Ставит таймеры на магазины.
- Смотрит статистику в вебе.
- Запрашивает выплаты.

2) Блогер:
- Всё то же, что SaaS, плюс акцент на ручной Force Post.
- Может публиковать "здесь и сейчас" без ожидания расписания.
- Та же веб-панель.

3) Администратор:
- Видит всех пользователей, каналы, балансы.
- Обрабатывает выплаты: отправить деньги / отклонить / принять чек.
- Переписывается с пользователями в чате выплат.
- Банит CPC, меняет тарифы, балансы, комиссию.
- Управляет бета-тестерами.
- Видит счётчики: активные SaaS, активные блогеры, висящие выплаты, ошибки за день.

Переключение ролей делает только админ. Обычный пользователь не может сам стать админом.

3. КАК РАБОТАЕТ БОТ (ВСЕ МЕНЮ И СЦЕНАРИИ)
================================================================================

Старт:
- Команда /start. Если человек пришёл по реферальной ссылке (start=код),
  реферер фиксируется.
- Показывается главное меню.

Главное меню (кнопки):
- "🏪 Магазины" — список CPA-магазинов с галочками вкл/выкл.
- "🚀 Force Post" — ручная публикация.
- "📊 Статистика" — ссылка в веб-панель.
- "💰 Баланс / Выплаты" — баланс, кнопка вывода.
- "❓ FAQ" — единая инструкция (раньше было две: для SaaS и для блогера).
- "👥 Рефералка" — ссылка, счётчик приглашённых, заработок.
- "⚙️ Настройки" — дублирует часть веб-настроек.

Магазины:
- Список с названиями. Нажатие — вкл/выкл.
- Особые случаи:
  * "Розовый кролик" — товары 18+. При включении бот показывает предупреждение:
    "Магазин содержит товары для взрослых. Убедитесь, что канал соответствует
    ограничениям 18+". Две кнопки: "🔞 Да, я подтверждаю" и "🔙 Отмена".
    Только после подтверждения магазин добавляется.
  * "Galaxy Store" — требует выбора города. Если город не выбран, бот открывает
    выбор города и не даёт включить магазин.
  * "Аквафор" и "Love Republic" — временно недоступны, бот отвечает ошибкой
    и не даёт включить.
  * Если магазин отключён на стороне конфига доступности — тоже ошибка.

Force Post:
- Шаг 1: выбор типа — CPA или CPC.
- CPA-ветка: бот подбирает случайный товар. Если у пользователя стоит
  "публиковать без предпросмотра" — публикует сразу во все активные каналы.
  Иначе — показывает предпросмотр (фото, текст, цена, ERID) с кнопками
  "✅ Опубликовать" и "❌ Отмена".
- Отдельный сценарий: выбор конкретного канала. Тогда пост уходит только
  в этот канал, а не во все.
- CPC-ветка: выбор активной кампании + выбор канала. Проверка правил.
  Если правила нарушены — предупреждение. Есть путь "опубликовать несмотря
  на нарушение" с отдельным подтверждением.

FAQ:
- Один общий текст. Разделы: что такое Force Post, как работают таймеры,
  что такое CPA/CPC, автоудаление, закрепление, выплаты, чеки, сроки (24 часа),
  блокировка за отсутствие чека.

Каналы:
- Пользователь добавляет канал (бот должен быть админом канала).
- У каждого канала: название, username/ID, sub_id (метка для статистики),
  вкл/выкл.
- Видео-каналы — отдельный список (платформа + ID канала), можно удалять.

Уведомления:
- По желанию: боту присылать сообщение о каждом опубликованном посте.

4. МАГАЗИНЫ И ТОВАРЫ (CPA)
================================================================================

Источник товаров — каталог Admitad (синхронизируется сервисом).
У каждого товара:
- Название, цена, валюта (обычно рубли), старая цена, % скидки.
- Фото.
- Партнёрская ссылка.
- ERID (обязательная маркировка рекламы в РФ). Без ERID товар не публикуется.
- Рекламодатель.
- Магазин-источник (например "Детский мир", "Розовый кролик" и т.д.).
- Признак "использовано" (чтобы не повторять один и тот же товар по кругу;
  когда всё использовано — цикл сбрасывается).

Фильтры:
- Минимальная скидка (0 = все товары). Настраивается в вебе.
- Только товары с ERID.
- Только из включённых пользователем магазинов.

Текст поста собирается по шаблону (настраивается в вебе):
- Заголовок, цена, скидка, рекламодатель, ERID, ссылка с subid и subid2,
  доставка, промокод, CTA-фраза ("Количество товара ограничено!" и т.п.).
- Для 18+ магазинов фото публикуется со спойлером.

AliExpress полностью удалён из системы по решению владельца. Никаких
товаров с него нет.

================================================================================
5. РЕКЛАМНЫЕ КАМПАНИИ (CPC)
================================================================================

CPC-кампания — это ручная рекламная карточка, не из каталога.
Поля кампании:
- Название (для себя).
- CPC-ссылка (куда вести).
- Текст поста.
- Картинка (URL).
- Описание, правила, доп. правила, разрешённые трафики (текстовые поля).
- Вкл/выкл.
- Интервал в часах/минутах (зарезервировано, фактически работают таймеры).
- Дни недели (зарезервировано на уровне кампании).
- Счётчики: когда последний раз публиковалась, сколько раз.

Модерация:
- При обычной публикации проверяются правила (стоп-слова, требования).
- При Force Post с нарушением — отдельное подтверждение.

Публикация CPC — только по точным таймерам (см. раздел 6). Интервального
фолбэка как у CPA нет.

Бан:
- Админ может забанить пользователю CPC целиком. Тогда все CPC-действия
  отвечают "CPC заблокирован".

================================================================================
6. РАСПИСАНИЕ ПУБЛИКАЦИЙ: ТАЙМЕРЫ, ИНТЕРВАЛ, ДНИ НЕДЕЛИ
================================================================================

Раньше был "циклический постинг" — он полностью удалён.

Сейчас три механизма, в порядке приоритета:

А) Точные таймеры (главный механизм):
- На каждый магазин и каждую кампанию можно поставить дату + время.
- Хранится как: пользователь, тип (магазин/кампания), ID цели, дата, время,
  признак "опубликовано".
- Когда время подошло — публикуется именно этот магазин/кампания,
  проверка интервала игнорируется.
- После публикации таймер помечается как выполненный.
- Если на сегодня несколько таймеров с прошедшим временем — берётся
  последний по времени (самый свежий).

Б) Интервал (запасной механизм, только для CPA):
- Настройка "Интервал между постами" в минутах (например 60 = 1 час).
- Работает только если на сегодня нет сработавших таймеров.
- Логика: смотрим время последнего опубликованного поста. Если прошло
  меньше интервала — пропускаем. Если больше — публикуем из всех включённых
  магазинов (случайный товар).
- Ввод в вебе: циферблат "часы : минуты" со стрелками вверх/вниз.
  Шаг минут — 5. Часы 0–23.

В) Дни недели (фильтр):
- Битовая маска: Пн=1, Вт=2, Ср=4, Чт=8, Пт=16, Сб=32, Вс=64.
- 127 = все дни. 0 = ни одного дня (публикаций не будет).
- Проверяется до всего остального: если сегодня не выбран — пользователь
  пропускается целиком.
- В вебе — круглые кнопки Пн..Вс, выбранные подсвечены красным.

Ночной режим:
- Глобальная пауза публикаций, например с 23:00 до 08:00 (настраивается).
- В ночные часы фоновые задачи сразу завершаются, ничего не публикуется.

7. ВЕБ-ПАНЕЛЬ ПОЛЬЗОВАТЕЛЯ (7 СТРАНИЦ)
================================================================================

Вход — по персональной ссылке с токеном (выдаёт бот). Без токена доступа нет.
Навигация:
- На компьютере: верхнее меню + боковая панель.
- На телефоне: кнопка-гамбургер (три полоски) вверху слева, открывает
  выезжающую панель слева, фон затемняется.

Список страниц и кнопок сайдбара:
1) 📊 Статистика
2) ⚙️ Настройки
3) 🛒 CPA магазины
4) 📢 CPC кампании
5) 🎨 Шаблоны
6) 💰 Выплаты
7) 📖 Выплаты (инструкция, раньше называлась "Гид")

--- 7.1. Статистика ---
- Карточки сверху: доступный баланс, ожидающий баланс, всего заработано,
  клики, лиды.
- Переключатель периода: "Всё время / 7 дней / 30 дней".
- Графики (линии и столбцы): клики по дням, лиды по дням, конверсия.
- Таблица "Сравнение каналов": по каждому каналу клики/лиды.
- Таблица "Последние транзакции": сумма, статус, заказ, дата.

--- 7.2. Настройки (3 вкладки) ---
Вкладка "Общие":
- Блок "Периодичность": циферблат часы:минуты + скрытое поле минут.
- Блок "Дни публикации": 7 круглых кнопок Пн–Вс.
- Блок "Посты": три галочки — авто-закреп на 24 часа, уведомлять о каждом
  посте, публиковать без предпросмотра. Поле "Автоудаление": выкл / 1ч / 6ч /
  12ч / 1 день / 2 дня / 3 дня / 7 дней (по умолчанию) / 14 дней / 30 дней.
- Блок "CPA": галочка "Автопубликация CPA включена".
- Блок "Фильтр": минимальная скидка % (0 = все).
- Блок "Налоговый статус": Не указан / Самозанятый-ИП / Физлицо.
- Кнопка "💾 Сохранить настройки" + строка результата
  ("✅ Настройки сохранены" зелёным или "❌ Ошибка" красным).

Вкладка "Видео-каналы":
- Список подключённых (платформа, ID, зелёная/красная точка активности).
- Форма добавления: выбор платформы + поле ID + кнопка.
- Кнопка "Удалить" у каждого.

Вкладка "Рефералка":
- Персональная ссылка вида https://t.me/ИМЯ_БОТА?start=КОД.
- Счётчики приглашённых и заработка.

--- 7.3. CPA магазины ---
- Список магазинов с переключателями.
- У каждого — кнопка "⏰ Таймер".
- Модалка таймера: календарь на месяц (Пн..Вс, дни-числа, стрелки месяцев),
  циферблат времени, кнопка сохранить.
- Сохранённые таймеры видны списком, каждый можно удалить.

--- 7.4. CPC кампании ---
- Список кампаний: название, текст, картинка, ссылка, вкл/выкл.
- Кнопки: создать, редактировать, удалить, поставить таймер.
- Таймер — та же модалка календарь+время, что и для магазинов.

--- 7.5. Шаблоны ---
- Три редактора: товарный пост, видео-пост, CPC-пост.
- Слева — текстовое поле шаблона, справа — кнопки-плейсхолдеры
  (название, цена, скидка, ERID, ссылка и т.д.).
- Кнопка предпросмотра: показывает как будет выглядеть пост на случайном
  товаре. Кнопки "Сохранить" и "Сбросить".

--- 7.6. Выплаты ---
- Баланс и кнопка "Запросить вывод".
- Список заявок: номер, сумма, статус-бейдж, дата.
- Клик по заявке — чат с админом (см. ниже).
- Чат: окно сообщений (400px высота, прокрутка), поле ввода + кнопка 📨.
  Сообщения админа — справа на тёмно-красном фоне, пользователя — слева
  на тёмно-зелёном. Время мелким серым.
- Если статус "ожидает чек" — виден блок загрузки чека: подпись
  "Вставьте ссылку на чек из Мой Налог (lknpd.nalog.ru)", поле для ссылки,
  кнопка "📤 Отправить чек".

--- 7.7. Выплаты-инструкция ---
- Заголовок "Загрузка чека (обязательно!)".
- Шаги: получить деньги → создать чек в Мой Налог (Продажа физ.лицу,
  услуга "Рекламные услуги") → вставить ссылку в веб-статистике.
- Предупреждение: срок 24 часа, иначе вечная блокировка и аннуляция денег.

================================================================================
8. ВЕБ-АДМИНКА
================================================================================

Вход — отдельная админ-ссылка с админ-токеном + проверка, что пользователь
в списке админов. Обычный токен не подойдёт.

Разделы:

--- Дашборд ---
- Счётчики: активных SaaS-пользователей, активных блогеров,
  висящих выплат (в обработке + ожидают чек + чек загружен),
  ошибок за сегодня.
- Последние каналы с владельцами.
- Последние ошибки системы.

--- Пользователи ---
- Таблица: ID, роль, тариф, подписка до, баланс, username.
- Клик — карточка редактирования: роль, дата подписки, тариф,
  доступный/ожидающий баланс, % комиссии, бан CPC (галочка).
- Кнопка сохранить → возврат к списку.

--- Выплаты ---
- Две таблицы: пользователи с балансом + список заявок.
- У заявки: ID, пользователь, сумма, сообщение, статус, ссылка-чека, дата.
- Действия по заявке (кнопки):
  * "Отправить деньги" — только из статуса "в обработке". Меняет на
    "ожидает чек", пишет в чат, шлёт уведомление в бот.
  * "Отклонить" — возвращает сумму на баланс, статус "отклонена",
    пишет в чат и в бот.
  * "Чек принят" — только из статуса "чек загружен". Статус "завершена",
    уведомление в бот.
- Кнопка "Чат" — переписка с пользователем по заявке.
- Прямая выплата: форма "ID пользователя + сумма" для ручной выплаты.

--- Чат выплат (админская сторона) ---
- То же окно, что у пользователя, но сообщения админа справа.
- Поле ввода + отправка. Автообновление каждые 10 секунд.

--- CPC-модерация ---
- Список кампаний с нарушениями/на проверке (название, владелец, текст).
- Действия: одобрить/заблокировать.

--- Бета-тестеры ---
- Форма: добавить ID. Список с кнопками удалить.
- Все действия логируются (кто, что, когда).

Логика статусов выплат (по кругу):
  processing (заявка создана)
  → awaiting_receipt (админ отправил деньги, ждём чек)
  → receipt_uploaded (пользователь вставил ссылку)
  → completed (админ принял чек)  ИЛИ  declined (админ отклонил, деньги вернулись)

================================================================================
9. ВЫПЛАТЫ, ЧЕКИ, НАЛОГИ (ПОДРОБНО)
================================================================================

Шаг за шагом:
1. Пользователь копит баланс (лиды из Admitad → деньги).
2. Нажимает "Вывести" в боте или вебе. Создаётся заявка (processing).
3. Админ проверяет, нажимает "Отправить деньги", делает перевод вручную.
   Статус → awaiting_receipt. Пользователю приходит уведомление в бот
   с кнопкой "Отправить чек".
4. Пользователь открывает "Мой Налог", создаёт чек: тип "Продажа физ.лицу",
   услуга "Рекламные услуги", сумма = сумме перевода.
5. Копирует ссылку вида https://lknpd.nalog.ru/... и вставляет в веб-панель
   в блоке чека. Нажимает "Отправить чек".
6. Проверка: ссылка обязана содержать "lknpd.nalog.ru". Чужие ссылки
   отклоняются с ошибкой.
7. Статус → receipt_uploaded. В чат падает системное сообщение с ссылкой.
8. Админ открывает ссылку, проверяет чек, нажимает "Чек принят".
   Статус → completed. Пользователю — "Выплата завершена".
9. Если чек не загружен за 24 часа — аккаунт блокируется навсегда,
   невыплаченные деньги аннулируются (правило написано в инструкции).

Налоговый статус (выбирает пользователь в настройках):
- Не указан.
- Самозанятый / ИП (бизнес-статус, может выдавать чеки).
- Физическое лицо.

Деньги:
- Минимальный вывод: 3000 рублей.
- Банковская комиссия ~4.3% + фиксированная часть ~35 руб (настройки).
- Балансы: доступный (можно выводить) и ожидающий (холд).

12. СЕКРЕТЫ И НАСТРОЙКИ (ЧТО ЕСТЬ, БЕЗ ЗНАЧЕНИЙ)
================================================================================

ВНИМАНИЕ: ниже — только НАЗВАНИЯ и назначение. Сами значения хранятся
в Railway Variables и передаются отдельно, в этот документ не вписываются.

Обязательные переменные окружения:
- BOT_TOKEN — токен Telegram-бота (получить у @BotFather).
- ADMIN_IDS — список Telegram-ID администраторов через запятую.
- ADMITAD_CLIENT_ID / ADMITAD_CLIENT_SECRET — ключи API Admitad для каталога
  и постбека. Выдаёт Admitad при партнёрстве.
- WEBAPP_BASE_URL — публичный адрес веба (например https://....railway.app).
- WEBAPP_ADMIN_URL — адрес админки (базовый URL + /admin).
- BOT_USERNAME — юзернейм бота без @ (для реферальных ссылок).
- PORT / WEBAPP_PORT / WEBAPP_HOST — порт и хост FastAPI (по умолчанию 8000).
- NIGHT_START / NIGHT_END — ночной режим (по умолчанию 23:00–08:00).
- RUN_INTERVAL_SECONDS — период фоновой проверки (по умолчанию 900 = 15 мин,
  фактически публикация CPA каждые 10 мин, CPC каждые 15 мин).
- PAYOUT_FIXED_FEE — фиксированная часть комиссии (по умолчанию 35).
- PAYOUT_BANK_PCT — процент банка (по умолчанию 0.043 = 4.3%).
- QUARANTINE_CHAT_ID — чат для битых постов/ошибок.
- DEEPINFRA_API_KEY — ключ для ИИ-генерации (если используется).

Файл базы: /app/data/autopost.db (на Railway — в volume /app/data).
Чеки-файлы (старые загрузки): /app/data/receipts/user_XXX/...
Настройки по умолчанию в коде: интервал 60 мин, дни 127 (все), автоудаление
168 часов (7 дней), мин. вывод 3000 руб.

Правила безопасности:
- Токены веб-панели — персональные, не передавать.
- Админ-токен — только у владельца.
- Файлы чеков отдаются только владельцу (проверка user_XXX в пути).
- Удаление аккаунта чистит: выплаты, чаты, каталог, транзакции, посты,
  каналы, кампании, расписания, согласия, рефералы.
